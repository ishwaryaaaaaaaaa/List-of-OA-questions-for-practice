Question 1: Even Number of Digits

Given an array of positive integers numbers, calculate how many of its elements have an even number of digits.

Example: numbers = [12, 134, 111, 1111, 10] → output 3 (12→2 digits, 134→3, 111→3, 1111→4, 10→2; three of them have an even digit count).

Constraints: 1 ≤ numbers.length ≤ 1000, 1 ≤ numbers[i] ≤ 10⁴. O(n²) time is fine.
======================================================================================================

Question 2: Smallest Value with Parentheses

You're given a string expr representing a sum of two positive integers with no zero digits (e.g. "741+12"). Add exactly one pair of parentheses around the + sign — with at least one digit between the plus sign and each parenthesis — so the resulting expression (interpreted as left * (sum) * right, where left/right are the digit groups outside the parentheses treated as multipliers) evaluates to the smallest possible value.

Example: expr = "112+422" → smallest is 1(12+42)2 = 108.
expr = "55+55" → smallest is (55+55) = 110.

Constraints: 3 ≤ expr.length ≤ 13. No zero digits. Both integers ≤ 10⁵. O(n⁴) time is fine.
=====================================================================================================

Question 3: ID Check Queue

People arrive at an event at given times (seconds since start). Each ID check takes 5 minutes (300 seconds). If someone arrives and sees more than 10 people already waiting in the queue (not counting whoever's currently being checked), they leave immediately — their "processed time" equals their arrival time. Otherwise they wait their turn. Ties: whoever was already in queue goes first. Return an array of times each person's ID check completes (or the time they left, if they left).

Example: times = [4, 400, 450, 500] → [304, 700, 1000, 1300].

Constraints: 1 ≤ times.length ≤ 1000, times strictly increasing, 0 ≤ times[i] ≤ 5×10⁴. O(n²) time is fine.
====================================================================================================


Question 4: Lamps Illuminating Exactly Once

You're given a 2D array lamps, where lamps[i] = [coordinate, radius]. Each lamp illuminates all integer points in [coordinate - radius, coordinate + radius]. Find how many integer coordinates are illuminated by exactly 1 lamp.

Example: lamps = [[-2,3],[2,3],[2,1]] → output 6 (points [-5,-4,-3,-2,4,5] are each covered by exactly one lamp).

Constraints: 1 ≤ lamps.length ≤ 10⁵, -10⁹ ≤ coordinate ≤ 10⁹, 1 ≤ radius ≤ 10⁵.
